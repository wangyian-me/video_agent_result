How these ads were made

Every ad here is generated end-to-end by Vignette, an agentic ad pipeline running on an A100 GPU cluster. A single product image plus a short creative brief go in; a finished vertical video ad — shots, voiceover, music, and cut — comes out. The two videos per ad let you compare image-to-video models on the same plan.

Pipeline

  1. Blueprint — a planner agent turns the product + brief into a structured ad spec: ordered shots, each with a role (hook, demo, CTA…), camera, action, voiceover, on-screen text, and mood — validated against a JSON schema.
  2. Keyframes — one hero image per shot (text-to-image), gated by a critic agent before any expensive video work.
  3. Video — each keyframe is animated into a short clip (image-to-video).
  4. Audio — per-shot voiceover (TTS) plus a music bed.
  5. Assemble — clips concatenated in shot order, voiceover timed to each shot, music ducked underneath, muxed to the final cut (ffmpeg).
  6. Critic — scores the result (the scorecard shown on each card).

Design choices

  • Agents reason, skills orchestrate, a provider shim runs the models. Every model sits behind one uniform request → submit → poll contract, so models are swappable from a registry without touching the pipeline.
  • Async on Slurm — jobs are submitted then polled; run state is file-based and resumable, so a preempted run picks up where it left off.
  • Full provenance — every generation logs its neutral→refined prompt and the file it produced, building a dataset for a future model-selection scorecard.

Models

  • Planning & critique: Claude (Opus). The keyframe critic scores each shot's hero image on a 7-metric rubric before any video is generated — the scorecard on each card. Each card also shows a second, independent critic — Qwen3-VL-32B — scoring the same keyframes on the same rubric, so each card shows a Claude-vs-QwenVL agreement table (neither is treated as ground truth). A third, post-video critic (Qwen3-VL-32B again, this time watching the rendered clips) scores a sampled subset on real motion — temporal stability, flicker, motion naturalness, label legibility under motion — and ranks LTX-2.3 vs Wan-Lightning head-to-head per shot (observed motion, not the keyframe critic’s prediction).
  • Keyframes: Qwen-Image (text-to-image). Chosen over FLUX specifically to fix product label / wordmark legibility — FLUX garbled on-pack text (e.g. "VOLLAGE" for VOLTAGE), Qwen renders it crisply, which is the biggest jump in the product-fidelity scores.
  • Video (two models, same plan): LTX-2.3 (22B distilled, audio-video foundation model, native synchronized audio) and Wan2.2-I2V-A14B with a 4-step Lightning distillation — ~3× faster than the base A14B (~85s/clip) at near-equal quality. Both render ~3.0s clips (LTX 73 frames @ 24fps, Wan 49 @ 16fps) so the two variants are the same length and each shot outlasts its voiceover. The "Wan2.2" column is the Lightning render; the "LTX" column is LTX-2.3.
  • Voiceover: Chatterbox-turbo TTS  ·  Music: ACE-Step

Multi-genre expansion — one pipeline, many genres

genre R&D ◆ Qwen-Image → LTX-2.3 (native audio) 🔊 sound on

The same genre-pluggable pipeline (genre-specialist planner → Qwen-Image keyframes → ref2img consistency lock → img2vid → native-audio assemble) driving four new genres beyond ads. Each 16s piece is rendered end-to-end on LTX-2.3 so the motion and its foley are generated jointly — the steak sizzles, rain patters, the brush scrubs, desert wind carries. Recurring subjects (the astronaut, the sneaker) are held identical across shots by the ref2img consistency layer. Play with sound.

The feedback loop — critic gate + reject sampling

agentic QA ◆ Claude-vision critic → targeted reroll

Generation is one-shot and unreliable, so every keyframe is judged before it earns an expensive video call. A vision critic scores each frame on the genre's rubric; a frame is rejected if its overall falls below the genre threshold (τ=6.5) or a floor-critical metric drops below the floor (4). Each rejected shot is then regenerated with a targeted fix derived from which metric failed — not a blind reseed — and re-judged, looping (cap 2×) until it passes. Only passing keyframes proceed to video. Across both genre batches (9 runs): 41/47 keyframes passed the gate first try; 8 reject-and-fix cases (shown below) — every one resolved after the loop.

The decisive pattern: most defects aren't bad luck on a seed, they're upstream. The critic caught a two-shoe sneaker and a three-knife reference that a blind reseed could never fix — the cause was the reference image, so the fix re-cast the reference. Others were prompt-level (a leaked #FF6B3D hex string rendered as on-frame text) or cross-shot (a green sand block breaking a continuous loop) — each fixed by changing what failed, not by rolling the dice again.

ASMR / satisfying — native-audio genre

genre R&D ◆ Qwen-Image → LTX-2.3 (native audio) satisfying🔊 sound on

The ad cards are silent clips + a separately-generated voiceover/music bed. The satisfying genre needs the opposite: the trigger sound (slice, crumble, squelch) has to land on the exact action frame — impossible with a bolt-on SFX layer. These use LTX-2.3, an audio-video model that generates the foley jointly with the video. Play with sound. The multi-shot pieces are concatenated through assemble.py's native audio-passthrough mode (each clip keeps its own synced track; an EBU-R128 loudnorm pass lifts the quiet foley to a consistent level) — the same pipeline that cuts the ads, routed to keep native audio for this genre.
